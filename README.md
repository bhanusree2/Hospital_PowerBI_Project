# Hospital Appointment & Waiting-Time Analysis | Power BI

An interactive Power BI report that analyzes hospital appointments, attendance, and waiting times across five departments.

### Key Features
- Total and completed appointment tracking
- No-show and cancellation analysis
- Department-wise appointment comparison
- Average waiting-time analysis
- Monthly trends and interactive filters

### Tools Used
Power BI Desktop, Power Query, DAX, CSV

### Dataset
1,800 appointments covering January to December 2025.

### Key Learning
Data cleaning, data modeling, DAX measures, and interactive healthcare operations reporting.
